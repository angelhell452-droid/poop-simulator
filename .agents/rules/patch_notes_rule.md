# Mandatory Patch Notes Rule

После каждого патча / обновления игры необходимо:
1. Записывать новые патч-ноты в `src/data/patchNotes.data.js`.
2. Обеспечивать работу кнопки `📜 Патчи` и клика по `#versionTag` для открытия истории патчей игроками прямо в игре.
3. Повышать версию в `index.html` и `package.json`.
4. Работать только с веткой `main`.
